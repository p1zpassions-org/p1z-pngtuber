# P1zTube

P1zTube โปรแกรม PNGtuber สำหรับ Windows (Electron)

## รันทดสอบ
1. ติดตั้ง Node.js
2. `npm install`
3. `npm start`

## สร้างตัวติดตั้ง (.exe)
`npm run dist` แล้วดูไฟล์ในโฟลเดอร์ `dist`

## ใช้กับ OBS
Window Capture หน้าต่างโปรแกรม + ฟิลเตอร์ Chroma Key (เลือกสีพื้นหลังที่ไม่ตรงกับโมเดลได้ในตั้งค่าตัวละคร > แสดงผล)
เมนูทั้งหมดจะหายเองเมื่อหน้าต่างไม่ได้โฟกัส หรือกดไอคอนแม่กุญแจเพื่อล็อกไม่ให้เมนูเด้ง

คีย์ลัดเป็นแบบ global (ตั้งในไอคอนฟันเฟือง) เกมแบบ Fullscreen แท้บางเกมอาจบล็อก แนะนำ Borderless Windowed

## ระบบอัปเดตอัตโนมัติ (GitHub Releases)
โปรแกรมที่ติดตั้งแล้วจะเช็กเวอร์ชันใหม่ตอนเปิด (ปิดได้ในฟันเฟือง) และมีปุ่ม "ตรวจสอบอัปเดต" ถ้ามีเวอร์ชันใหม่จะขึ้นป๊อปอัพถามว่าจะอัปเดตไหม

**ตั้งค่าครั้งแรก**
1. เปิด `package.json` แก้ `YOUR_GITHUB_USERNAME` ในส่วน `build.publish` เป็นชื่อผู้ใช้ GitHub ของคุณ (และชื่อ repo ถ้าไม่ใช่ `p1z-pngtuber`)
2. repo ต้องเป็น Public
3. รัน `npm install` ใหม่ (มีแพ็กเกจ `electron-updater` เพิ่ม)

**ปล่อยเวอร์ชันใหม่**
1. แก้ `version` ใน `package.json` เช่น `1.0.1`
2. commit แล้ว push จากนั้นสร้าง tag ให้ตรงกับเวอร์ชัน
   ```
   git tag v1.0.1
   git push origin v1.0.1
   ```
3. GitHub Actions จะ build และแนบไฟล์ติดตั้งใน Releases เอง (หรือจะ build เองด้วย `npm run release` โดยตั้ง `GH_TOKEN` ก็ได้)

**ทดสอบ:** ติดตั้ง 1.0.0 จากไฟล์ติดตั้ง แล้วปล่อย 1.0.1 ขึ้น Releases เปิดโปรแกรม 1.0.0 ควรขึ้นป๊อปอัพ
(ระบบอัปเดตใช้ได้เฉพาะโปรแกรมที่ติดตั้งแล้ว ไม่ทำงานตอน `npm start`)

หมายเหตุ: ไม่ได้เซ็นโค้ด Windows จะขึ้นหน้าจอเตือน SmartScreen ตอนติดตั้งครั้งแรก
